Programming for AI – Assignment 3
How to Run:
Install Python and the required libraries: NumPy, Pandas, Matplotlib and Pillow. Open `Assignment3_Programming_for_AI.ipynb` in Jupyter Notebook. Keep the provided datasets inside the `data` folder and run all cells from top to bottom.
 One Thing I Found Difficult:
Creating the dashboard was challenging because I had to combine different types of graphs into one figure while keeping everything clear and readable. Adjusting the layout, labels and scales took some trial and error.
